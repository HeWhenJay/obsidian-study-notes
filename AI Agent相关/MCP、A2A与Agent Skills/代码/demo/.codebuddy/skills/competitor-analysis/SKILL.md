# 竞品分析 Skill

## 目的
本Skill提供系统化的竞品分析流程,帮助用户高效收集、整理和分析竞争对手信息,生成专业的竞品分析报告。

## 使用场景
当用户提出以下需求时使用本Skill:
- 竞品研究和数据收集
- 市场竞争对手分析
- 产品功能对比
- SWOT分析(优势、劣势、机会、威胁)
- 竞争情报收集和分析
- 行业竞争格局分析
- 竞争对手策略分析

## 工作流程

### 1. 确定分析范围
首先明确竞品分析的具体需求:
- 目标竞争对手名单
- 分析维度(产品、市场、技术、商业模式等)
- 分析深度和粒度
- 分析目的和目标

### 2. 数据收集
使用 `scripts/竞品数据收集.py` 脚本辅助数据收集:
- 运行脚本收集公开信息
- 支持多平台数据抓取(官网、应用商店、社交媒体)
- 自动化数据整理和标准化

手动收集补充信息:
- 使用 web_search 工具搜索最新资讯
- 使用 web_fetch 工具获取官网和产品页面信息
- 收集用户评价和反馈

### 3. 数据整理
将收集的数据结构化整理:
- 产品信息(功能、定价、定位)
- 市场数据(市场份额、用户规模、增长率)
- 技术特点(技术栈、核心能力)
- 商业模式(盈利模式、收入来源)
- 用户群体(用户画像、市场细分)

### 4. 对比分析
使用 `references/竞品分析框架.md` 进行系统化分析:
- 使用提供的分析框架模板
- 进行多维度对比
- 识别差异化优势
- 发现市场机会和威胁

### 5. 生成报告
基于分析结果生成专业报告:
- 执行摘要
- 竞品概况
- 详细对比分析
- SWOT分析
- 结论和建议

## 技能资源

### Scripts
- `scripts/竞品数据收集.py`: 自动化竞品数据收集脚本,支持多平台信息抓取和数据整理

### References
- `references/竞品分析框架.md`: 标准化的竞品分析框架,包含分析模板、评估维度和评分标准

### Assets
- `assets/分析报告模板.md`: 竞品分析报告模板,可直接用于生成报告

## 最佳实践

1. **明确目标**: 始终从分析目的出发,避免盲目收集数据
2. **多源验证**: 对关键信息进行多源交叉验证
3. **持续更新**: 竞品信息变化快,建议定期更新分析
4. **聚焦核心**: 优先分析核心竞争对手和关键维度
5. **数据驱动**: 基于客观数据进行分析,避免主观臆断

## 注意事项
- 遵守法律法规和平台规则,不进行非法数据采集
- 尊重竞争对手的商业机密和知识产权
- 注重数据来源的可信度和时效性
- 分析结果仅供内部决策参考
