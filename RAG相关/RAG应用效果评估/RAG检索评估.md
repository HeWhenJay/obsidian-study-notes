## 常见指标——上下文相关性（Context Relevance / Context Relevancy）

上下文相关性评估检索出的上下文与输入问题之间的相关程度。它关注每个检索片段是否真正有助于回答问题，而不是只看片段主题是否大致相近。

### 例子

若用户提问：“埃菲尔铁塔的建造年份？”

检索器返回：

1. “埃菲尔铁塔于 1887 年动工，1889 年竣工。”
2. “巴黎是法国的文化中心。”

分析：第一个片段直接包含建造年份，应具有较高相关性；第二个片段虽然与巴黎相关，但不能回答建造年份，应具有较低相关性。

## 常见指标——上下文精度（Context Precision）

上下文精度在不同工具和资料中的定义会略有差异。

在 Ragas 等 RAG 评估工具中，Context Precision 更偏向衡量相关上下文是否排在更靠前的位置，也就是检索排序质量。可以理解为：越相关、越能支持参考答案的片段排得越靠前，Context Precision 越高。

在业务分析中，也可以把它简化理解为上下文中相关信息所占比例：

```text
Context Precision = 上下文中与问题相关的信息数量 / 上下文总信息数量
```

### 例子

问题：“苹果公司的总部在哪里？”

上下文：“苹果公司（Apple Inc.）成立于 1976 年，总部位于美国加利福尼亚州库比蒂诺市，CEO 是蒂姆・库克，主要产品包括 iPhone 和 Mac。”

分析：如果按“相关信息占比”的简化理解，问题关注“总部位置”，上下文中只有“加利福尼亚州库比蒂诺市”直接相关，其余成立时间、CEO、产品与问题无关，所以精度较低。如果按排序质量定义，还需要看相关片段是否被排在前面。

## 常见指标——上下文召回率（Context Recall）

上下文召回率评估上下文中是否包含回答问题所需的全部关键信息。有时也可近似理解为回答所需证据的覆盖率。

```text
Context Recall = 上下文中包含的关键信息数量 / 参考答案中的关键信息数量
```

### 例子

问题：“《三体》的作者是谁？哪一年开始连载？”

参考答案：“刘慈欣，2006 年。”

上下文：“刘慈欣，中国科幻作家，2006 年开始在《科幻世界》连载《三体》。”

分析：参考答案的关键信息是“刘慈欣”和“2006 年”，上下文均包含，所以召回率高。

反例：若上下文仅包含“刘慈欣”，未提“2006 年”，则召回率下降。
