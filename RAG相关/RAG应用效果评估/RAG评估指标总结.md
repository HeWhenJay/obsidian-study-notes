## 指标等级标准

以下阈值只能作为经验参考，实际标准应根据业务风险、测试集难度、评估工具和评估模型来调整。

| 指标 | 高 | 中 | 低 | 满分 |
| --- | --- | --- | --- | --- |
| context_recall | >= 0.8 | 0.5 ~ 0.8 | < 0.5 | 1.0 |
| context_precision | >= 0.7 | 0.4 ~ 0.7 | < 0.4 | 1.0 |
| faithfulness | >= 0.9 | 0.7 ~ 0.9 | < 0.7 | 1.0 |
| answer_relevancy / response_relevancy | >= 0.9 | 0.7 ~ 0.9 | < 0.7 | 1.0 |

## 诊断性能瓶颈：对症下药的前提

| 指标 | 可能的问题场景 | 核心问题指向 |
| --- | --- | --- |
| context_recall 低 | 检索器未覆盖关键文档、知识库缺失、embedding 模型语义匹配能力不足、查询改写不足等 | 检索器 |
| context_precision 低 | 检索器返回大量无关文档、向量数据库索引或过滤策略有误、相关文档排名低、Top-K 过大等 | 检索器 |
| faithfulness 低 | 生成模型未严格遵循上下文、提示词未明确要求基于上下文回答、上下文过长导致信息稀释或包含矛盾信息等 | 生成器 |
| answer_relevancy / response_relevancy 低 | 生成模型未准确理解问题意图、问题复杂但未分解、上下文与问题关联性弱、回答结构不符合用户需求等 | 生成器 |
| 四个指标均低 | 系统性问题，优先检查检索质量；也可能是问题本身超出知识库或系统能力范围 | 检索器优先 |

## 提升 context_recall（上下文召回率）

检索器增强：

- 混合检索：结合 BM25（关键词匹配）和向量检索。例如在医疗场景中，使用 BM25 召回包含特定症状术语的文档，再用向量检索补充语义相关病例。
- 查询改写：通过 LLM 将用户问题扩展为多个同义表达或子问题。例如将“如何治疗糖尿病”改写为“糖尿病的药物治疗方案”和“糖尿病的饮食管理方法”，提升检索覆盖范围。

知识库优化：

- 数据清洗：去除重复、过期或低质量文档，确保检索空间有效。
- 增量更新：定期补充新数据，并重新构建索引或刷新向量，避免知识滞后。

## 提升 context_precision（上下文精度）

- 重排序：对检索结果进行二次排序，例如在法律场景中，优先展示与案件类型匹配的法律条文。
- 分块策略优化：使用语义分块、调整块大小、动态分块，减少无关信息和语义断裂。
- 检索参数调整：优化 Top-K、相似度阈值、混合检索权重，通过实验平衡召回率和精度。

## 提升 faithfulness（忠实度）

生成器约束：

- 提示词工程：在提示中明确要求“仅基于提供的上下文回答”，并要求无法从上下文判断时直接说明信息不足。
- 事实核查：在生成答案后，使用 LLM 或规则对答案中的事实进行二次验证。

上下文质量增强：

- 截断策略：上下文太长时优先保留更可能含有关键证据的片段，避免中间信息丢失或重要证据被稀释。
- 元数据增强：为每个文档块添加标题、来源、时间、关键词等元数据，帮助生成模型定位关键信息。
- 上下文压缩和过滤：去除冗余、无关或矛盾内容，提升上下文纯度和语义完整性。

## 提升 answer_relevancy / response_relevancy（答案/响应相关性）

问题理解优化：

- 问题分类：对用户问题进行分类，如事实型、比较型、建议型，并针对不同类型生成结构化提示。
- 问题分解：对于复杂问题，先拆解子问题，再分别检索和回答。
- 多轮澄清：当用户问题不明确时，引导用户补充约束，而不是直接生成泛泛回答。

生成策略调整：

- 摘要压缩：对上下文进行摘要或过滤，去除冗余信息后再输入生成器，提升回答针对性。
- 回答格式约束：按用户问题要求输出步骤、表格、结论或对比项，减少答非所问。

## 核心指标通用基准范围（参考）

- Faithfulness：>= 0.85 通常是较高目标；低于 0.7 可能说明存在明显幻觉或上下文依据不足。
- Answer Relevancy / Response Relevancy：>= 0.8 通常能保证较好的用户体验；低于 0.6 往往说明回答明显偏题或不完整。
- Context Recall：>= 0.7 ~ 0.8 是常见目标；知识密集、高风险场景通常需要更高召回。
- Context Precision：>= 0.7 通常是较好的起点；高风险场景应进一步提高，并结合人工抽样检查。
